# racion2cart: хэндаут для запуска на ПК через Claude Desktop

Задача: превратить неделю из racion.app в таблицу товаров Пятёрочки (доставка, СПб).
Это **этап 1, только чтение каталога**. Корзину скрипт не трогает (это этап 2, он ещё не одобрен).

Почему на ПК: 5ka.ru пускает только российский домашний IP и настоящий браузер.
Из облака каталог закрыт (подробности в `RECON.md`). Рацион открыт отовсюду.

---

## 0. Что нужно на ПК

- Python 3.11+ (`python --version`), git, Google Chrome (без него возьмётся Chromium из Playwright).
- Российский IP без VPN.
- Claude Desktop, вкладка **Code**: она выполняет команды на твоём компьютере. Открой в ней пустую папку.

## 1. Промпт для Claude Desktop (скопируй целиком)

```
Мы запускаем этап 1 проекта racion2cart: план недели из racion.app → таблица товаров Пятёрочки
(доставка, Санкт-Петербург). Код уже написан, его нужно установить, запустить и при необходимости
поправить под реальные ответы 5ka.ru. Подробная инструкция — racion2cart/HANDOUT.md, разведка API —
racion2cart/RECON.md. Прочитай оба файла перед началом.

Жёсткие правила:
- НЕ добавлять ничего в корзину 5ka, НЕ оформлять заказ, НЕ вызывать никакие POST/PUT/DELETE к 5ka.ru.
  Только чтение каталога (GET через r2c/fivka.py).
- Пауза между запросами к 5ka не меньше 1,5 с (pause_s в config.toml), никаких параллельных запросов.
  Поиск кэшируется в .cache/ на 12 часов — не сбрасывай кэш без нужды.
- config.toml, .profile/, .cache/, out/ не коммитить (они в .gitignore): там адрес и ссылка на план семьи,
  а репозиторий публичный.
- Если 5ka показывает капчу или «я не робот» — останови выполнение и попроси меня пройти её в окне браузера.
- После каждого шага (2–6 из HANDOUT.md) покажи мне результат и жди моего «ок».

Шаги:
1. Клонируй ветку и поставь зависимости (раздел 2 HANDOUT.md).
2. python -m r2c plan — проверь, что список из Рациона читается.
3. python -m r2c probe --wait — откроется Chrome: я выставлю адрес доставки (и при желании залогинюсь),
   ты покажешь вывод: заголовки, магазин доставки, пробный поиск.
4. python -m r2c match --limit 5 — пробный прогон на 5 позициях, покажи out/table.md.
   Если поля ответа 5ka отличаются от ожидаемых (раздел 5 HANDOUT.md) — поправь r2c/fivka.py
   или r2c/matcher.py и прогони тесты: python -m unittest tests.test_matcher
5. python -m r2c match — полный прогон, покажи out/table.md целиком.
6. Вместе со мной разбери строки 🟡/🔴/⚫: для каждой предложи query, plu или avoid_words
   в config.toml, перезапусти match и покажи, что изменилось.
```

## 2. Установка

Windows (PowerShell):

```powershell
git clone -b claude/racion-to-pyaterochka-cart-kwnmbj https://github.com/tvsm22/bullseye-market.git
cd bullseye-market\racion2cart
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium
copy config.example.toml config.toml
```

macOS / Linux: то же, но `source .venv/bin/activate` и `cp config.example.toml config.toml`.

В `config.toml` впиши:

```toml
plan = "https://racion.app/plan/<id твоей недели>"
address = "Россия, Санкт-Петербург, <улица>, <дом>"
```

## 3. Команды

| Команда | Что делает | Ходит в 5ka |
|---|---|---|
| `python -m r2c plan` | список покупок из Рациона: что, сколько грамм реально нужно, как округлил Рацион | нет |
| `python -m r2c probe --wait` | открывает Chrome с постоянным профилем, показывает магазин доставки и пробный поиск, ждёт Enter | да, 1–3 запроса |
| `python -m r2c match --limit 5` | сопоставление первых 5 позиций | да |
| `python -m r2c match` | всё → `out/table.md` и `out/table.csv` | да, ~1 запрос на позицию |
| `python -m r2c match --only milk,eggs` | только эти ingredientId | да |

Полный прогон на ~56 позиций займёт около 2–3 минут из-за пауз. Повторный прогон в течение 12 часов
почти мгновенный: поиск берётся из кэша.

## 4. Как скрипт решает, что брать

1. **Что покупать.** Как кнопка «Собрать корзину» в Рационе: пропускает отмеченное «куплено»,
   «обычно есть дома» (специи, масло, мука — `include_pantry = false`) и «уже есть дома»;
   свои товары из списка Рациона ищет по названию. Не покупать что-то совсем: `skip = ["white_wine"]`.
2. **Магазин.** `sap_code` из конфига → адрес, выставленный на 5ka.ru в окне браузера → `address`.
   Ассортимент и цены берутся в режиме доставки (`mode = "delivery"`).
3. **Поиск.** Запрос берётся из `[ingredients.<id>].query`, иначе из встроенного словаря
   (`DEFAULT_QUERIES` в `r2c/matcher.py`: «Помидоры» → «томаты» и т. п.), иначе из названия в Рационе.
4. **Совпадение названия.** Доля слов запроса в названии товара; главное слово должно стоять в начале
   («сыр» ≠ «чипсы со вкусом сыра»); жирность в % должна совпасть; `prefer_brands` дают бонус,
   `avoid_words` исключают товар; товары не в наличии отбрасываются.
5. **Фасовка и количество.** Считается от того, сколько реально уйдёт в блюда (`needed`), а не от округления
   Рациона. Штучный товар: упаковок = ⌈нужно / фасовка⌉ (допуск 3 %). Весовой (`uom = кг`): вес с шагом
   `step`. Из подходящих по названию выбирается вариант с наименьшим остатком (корзинами по 25 %),
   затем самый дешёвый, затем с меньшим числом упаковок.
6. **Уверенность.** 🟢 — название совпало ≥85 % и фасовка понятна, либо товар закреплён через `plu`;
   🟡 — совпадение 60–85 % или что-то с фасовкой; 🔴 — ниже; ⚫ — ничего не нашлось.
   Для 🟡/🔴 в разделе «Проверить» показаны до 3 альтернатив со ссылками.

Закрепить выбор навсегда (со второй недели такие позиции будут 🟢 без угадывания):

```toml
[ingredients.milk]
plu = "1234567"          # PLU из колонки plu или alt_plu в out/table.csv
```

## 5. Что ожидается от 5ka (если упадёт — сверить)

Запросы идут `fetch`-ем изнутри открытой страницы 5ka.ru с заголовками `x-app-version`, `x-device-id`,
`x-platform`, которые подсмотрены у собственных запросов сайта.

- `GET https://5d.5ka.ru/api/catalog/v3/stores/{sap}/search?mode=delivery&include_restrict=true&q=…&limit=20`
  → `{"products": [{plu, name, property_clarification: "930 мл", uom: "шт"|"кг", step, min_weight,
  prices: {regular, discount, cpd_promo_price}, is_available}, …]}`
- `GET https://5d.5ka.ru/api/orders/v1/orders/stores/?lat=…&lon=…` → `{sap_code, shop_address, has_delivery}`
- `localStorage["DeliveryPanelStore"].selectedStore.sapCode` — магазин, выбранный в шапке сайта.
- Ссылка на товар собирается как `https://5ka.ru/product/{plu}/`. Если она не открывается,
  поправь `Option.url` в `r2c/matcher.py` по ссылке из адресной строки сайта.

Типовые сбои:

| Симптом | Что делать |
|---|---|
| «5ka.ru так и не открылся» | проверить, что VPN выключен; запустить без `--headless`; пройти капчу в окне |
| `Blocked: антибот не пускает` | подождать 10–15 минут, увеличить `pause_s`; не перезапускать в цикле |
| пустой `products` | попробовать `mode = "store"`; проверить, что адрес доставки выставлен |
| нет `x-device-id` в заголовках | сайт не успел сходить в API: обновить страницу в окне, пройтись по каталогу |

## 6. Что прислать обратно

- `out/table.md` после полного прогона (и, если были правки кода, `git diff`).
- Вывод `python -m r2c probe`: какой магазин доставки выбрался.
- Список позиций, где выбор скрипта не устроил, и что ты выбрал бы сам. Из этого допишем словарь запросов
  и предпочтения.

## 7. Замечания по твоей неделе (05.10.2026)

- В плане есть «Вино белое сухое». Алкоголь доставкой, скорее всего, не продают
  (дистанционная продажа алкоголя в РФ запрещена, но проверь на сайте). Если не найдётся,
  добавь `skip = ["white_wine"]`.
- Цены Рациона — оценка по Росстату с поправкой на Пятёрочку (15 915 ₽ на неделю), не цены полки.
  В таблице будут обе суммы.
